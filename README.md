# evvvvvvmusic.vvv
short for "extract vvvvvvmusic.vvv"

simple program to extract the music from VVVVVV.

## how to use
- make sure the compiled binary and the vvvvvvmusic.vvv file are in the same directory
- create the necessary directory structure (data/music/ for the default file)
- run the program with no arguments
